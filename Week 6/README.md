# Week 6 - Generative AI Programming (Release v0.1)

## Prerequisites (Windows)
- Python 3 installed (`py --version`)
- Ollama installed (`ollama --version`)
- VS Code (optional)

## Run in PowerShell

```powershell
cd "$HOME\Downloads\week6"  # Change to wherever you extracted this folder
py -m pip install -r requirements.txt
ollama pull llama3.2
# Ensure Ollama is running, then in another PowerShell window:
py main.py
```

## Verify

The baseline runs 30 questions, prints PASS or REVIEW according to
keyword coverage (60% threshold), and generates `baseline_results.csv`.

- The document's step 5 says `requirements.py`, but the actual file is `requirements.txt`.
- CSV is generated by running `main.py`, not included in this archive.
